# How rooms, items and puzzles are made

The game is data. Run **Big Night Out > Build Game** in Unity after changing any of these, and it rebuilds every scene.

- `Assets/_Project/World/*.json`: items, item combinations, rooms, entry points and hotspots. One file per act.
- `Assets/_Project/Dialogue/*.yarn`: every line and every puzzle rule (Yarn Spinner).
- `Assets/_Project/Art/Painted/*.png`: finished art, generated by `tools/art/*.py`. Missing art falls back to coloured blocks.
- `python3 tools/check_world.py` checks that every node, item, room and entry referenced anywhere exists.

## Coordinates
A room is 19.2 x 10.8 units (1920 x 1080 pixels, 100 pixels per unit), with (0, 0) in the middle.
pixel_x = (x + 9.6) * 100 and pixel_y_from_top = (5.4 - y) * 100. The back wall meets the floor near y = -2.5;
the player walks between y = -5 and y = -2.6 unless the room sets `walkable`.

## JSON fields
- item: `id`, `name`, `color` (placeholder colour). Each item needs a Yarn node `Item_<id>_Look`.
- combination: `a`, `b`, `node` (item ids in either order).
- room: `id`, `scene` (unique scene name), `onEnter` (node), `wall`, `floor` (placeholder colours),
  `walkable` (optional flat list of x, y pairs), `entries` (`name`, `pos`, `faceLeft`), `hotspots`.
- hotspot: `name` (hover text, and its art file `hs_<name in snake_case>.png`), `feet` (bottom centre), `size`,
  `standAt` (where Dex walks to), `faceLeft`, `look`, `use` (nodes), `items` (`item`, `node`),
  `hideWhenFlag`, `showWhenFlag`.

## Yarn commands and functions
`<<give id>>` `<<take id>>` `<<flag name>>` `<<unflag name>>` `<<add counter n>>` `<<act n>>` `<<go room_id entry>>`,
plus `<<jump Node>>` and options (`-> text <<if condition>>`).
Functions: `has("id")`, `flagged("name")`, `counter("name")`, `current_act()`.
Node names must be unique across all files: prefix each act's nodes (A2_, A3_, ...).
